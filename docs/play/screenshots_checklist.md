# Checklist de screenshots para Google Play

## Capturas sugeridas

- [ ] Resumen de cartera.
- [ ] Monedas y posiciones.
- [ ] Historial de movimientos.
- [ ] OCR con vista previa o formulario editable.
- [ ] Alertas locales.
- [ ] Más / Centro de control.
- [ ] Google Drive backup/restore.
- [ ] Exportaciones CSV, JSON, PDF y XLSX.

## Preparación visual

- [ ] Usar datos demo o una cartera preparada para publicación.
- [ ] Evitar montos, correos, notas, IDs de operación y cuentas reales.
- [ ] Difuminar información sensible si no puede evitarse.
- [ ] Usar el modo visual premium y una apariencia consistente.
- [ ] Tomar capturas verticales, limpias y con buena legibilidad.
- [ ] Ocultar notificaciones privadas de la barra superior.
- [ ] Evitar mostrar correos en las pantallas Firebase o Google Drive.
- [ ] Cerrar diálogos, teclados, loaders y mensajes temporales.
- [ ] Mantener idioma, formato de moneda y hora consistentes.
- [ ] No mostrar pantallas de login de terceros como material promocional.

## Validación para Play Console

- [ ] Confirmar las dimensiones y cantidad exigidas actualmente por Play.
- [ ] Verificar que no haya bordes, recortes o escalado borroso.
- [ ] Asegurar que cada captura corresponda a la versión enviada.
- [ ] No incluir promesas de rendimiento financiero.
- [ ] No insinuar que CriptoControlMx es wallet, exchange o custodio.
- [ ] Revisar todas las imágenes a tamaño completo antes de subirlas.
