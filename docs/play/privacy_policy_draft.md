# Política de privacidad de CriptoControlMx

**Estado:** borrador para publicación

**Última actualización:** 4 de julio de 2026

CriptoControlMx, en adelante “la aplicación”, es desarrollada por
CriptoControlMx. Para dudas o solicitudes relacionadas con privacidad puede
escribir a **criptocontrolmx@gmail.com**.

## 1. Finalidad de la aplicación

CriptoControlMx es una herramienta de control personal de cartera de
criptomonedas. Permite registrar y consultar información proporcionada por el
usuario, crear respaldos y generar reportes.

La aplicación:

- no permite comprar, vender ni intercambiar criptomonedas;
- no permite transferir, custodiar ni retirar criptomonedas;
- no funciona como wallet ni exchange;
- no ofrece asesoría financiera personalizada;
- no ofrece préstamos, servicios bancarios, apuestas, financiamiento ni
  inversiones administradas.

## 2. Datos que puede manejar

Dependiendo de las funciones que el usuario decida utilizar, la aplicación
puede manejar:

- **Datos de cuenta:** correo electrónico, nombre visible e identificadores de
  cuenta proporcionados por Google Sign-In o Firebase Authentication.
- **Datos financieros ingresados por el usuario:** movimientos, montos,
  monedas, cantidades, comisiones, precios, posiciones, notas e instantáneas
  de cartera.
- **Archivos y documentos:** capturas seleccionadas para OCR, copias de
  seguridad y exportaciones CSV, JSON, PDF o XLSX.
- **Datos técnicos y de diagnóstico:** interacciones básicas, fallos, registros
  de errores y datos técnicos, únicamente cuando el usuario autoriza Analytics
  o Crashlytics.
- **Identificadores técnicos:** identificadores necesarios para prestar
  funciones de Firebase, Google Sign-In y Google Drive.

La captura elegida para OCR se procesa en el dispositivo para extraer texto.
CriptoControlMx no sube automáticamente la imagen ni el texto reconocido a
Firebase, Google Drive, Analytics o Crashlytics.

## 3. Uso de los datos

Los datos se utilizan, según las funciones elegidas, para:

- autenticar y administrar la sesión opcional del usuario;
- guardar y mostrar la cartera en el dispositivo;
- subir o restaurar manualmente el estado financiero mediante Firebase;
- crear o restaurar manualmente una copia en el espacio privado de la
  aplicación en Google Drive;
- importar, generar y compartir exportaciones solicitadas por el usuario;
- procesar capturas mediante OCR y presentar un formulario editable;
- ejecutar alertas locales;
- diagnosticar errores y conocer el uso general de funciones cuando existe
  consentimiento.

El usuario decide si inicia sesión y si utiliza Firebase, Google Drive,
exportaciones, Analytics o Crashlytics. La sincronización con Firebase y las
copias de Google Drive no se ejecutan automáticamente.

## 4. Proveedores y compartición

CriptoControlMx no vende datos personales ni financieros y no comparte datos
con anunciantes. No utiliza los datos para publicidad.

Cuando el usuario activa determinadas funciones, los datos necesarios pueden
ser procesados por proveedores de servicio de Google, entre ellos:

- Google Sign-In;
- Firebase Authentication;
- Cloud Firestore;
- Google Drive;
- Firebase Analytics, si el usuario lo autoriza;
- Firebase Crashlytics, si el usuario lo autoriza.

El tratamiento realizado por esos servicios también está sujeto a las
condiciones y políticas de privacidad de Google.

## 5. Seguridad

Las comunicaciones con los servicios cloud de Google utilizan conexiones
seguras durante la transmisión. Aun así, ningún sistema puede garantizar
seguridad absoluta.

Las copias y exportaciones creadas o compartidas por el usuario pueden quedar
fuera del control de la aplicación. El usuario es responsable de proteger sus
archivos, cuentas, dispositivos y enlaces de compartición.

## 6. Retención y eliminación

- Los datos locales permanecen en el dispositivo hasta que el usuario los
  elimine, restablezca los datos financieros, borre los datos de la aplicación
  o la desinstale.
- Cerrar sesión no elimina automáticamente los datos locales ni las copias
  cloud.
- Los datos subidos manualmente a Firebase permanecen hasta que se eliminen del
  servicio o se solicite su eliminación.
- Las copias de Google Drive permanecen bajo la cuenta Google del usuario. El
  usuario puede administrar el acceso y los datos asociados desde su cuenta
  Google o Google Drive.
- Los archivos exportados permanecen donde el usuario decida guardarlos o
  compartirlos.

Para solicitar acceso o eliminación de datos asociados a los servicios de la
aplicación, escriba desde el correo de la cuenta afectada a
**criptocontrolmx@gmail.com**. Podremos solicitar información razonable para
verificar la identidad y localizar los datos.

## 7. Menores de edad

La aplicación no está dirigida a niños ni está diseñada para recopilar
deliberadamente información de menores.

## 8. Cambios a esta política

Esta política puede actualizarse para reflejar cambios legales, técnicos o
funcionales. La versión vigente mostrará su fecha de actualización.
